# Semaforo-Esp32-Dev-Kit
Simulação de semáforo com botão de travessia de pedestres com ESP32 DevKit no Wokwi. Ao pressionar o botão, o código em C++ encerra o verde dos carros, pisca vermelho e amarelo e libera o verde para o pedestre, usando 5 LEDs e debounce. Desenvolvida como parte de um portfólio prático de sistemas embarcados.
